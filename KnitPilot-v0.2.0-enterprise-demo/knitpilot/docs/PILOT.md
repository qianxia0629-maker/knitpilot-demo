# KnitPilot 企业试用说明

## 试用目标

让工艺师用非敏感的基础圆领套头衫数据完成一轮：修改尺寸 → 生成初稿 → 查看部件技术图 → 核对 QC → 下载 JSON。记录哪一步不符合工厂习惯，以及人工修正原因。界面是操作演示，当前不承担生产交付。

## 给试用方的简短说明

1. 打开提供的 `/demo/` 地址，输入单独发给你的演示访问码。
2. 先直接点击“生成工艺初稿”，确认前片、后片、袖片、领条和 QC 都能显示。
3. 在“成衣尺寸”修改一个数值，重新生成，观察针数/转数与 QC 变化。
4. 在前片或后片技术图点击 ① 袖窿、② 领窝，查看对应计算序列。
5. 如需反馈，记下工厂原本会怎么做、实际希望得到的数值和原因。请不要输入客户款号、完整机密工艺单或其他敏感资料。

## 收集的反馈

记录：款式与肩型是否在 V1 范围；尺寸量法及单位；密度与缩水率测量口径；哪项输出/式子不符合工厂规则；期望修正值与原因；用户操作困难点。收到真实样本后应在隔离的数据环境、权限设计和保密约定到位后再处理。
